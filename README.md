## 🌟 Featured Projects & Implementations

### 1. 📊 [Interactive Accounts Receivable Executive Dashboard (Live Demo)](https://edwardsantacruz35-ui.github.io/tablero-cxc/)
> **Live Web Application:** Interactive debt management portal tracking **$400K+ USD** in active receivables across 600+ corporate invoices.
- **Key Features:** Real-time KPI cards, aging breakdown (Current vs 15-day / 30-day overdue), dispatch/delivery validation filter, and collection officer performance analysis.
- **Stack:** HTML5, TailwindCSS, Chart.js, GitHub Pages, Automated Data Sync.

### 2. 🤖 [Autonomous Desktop ERP RPA Bot (Computer Vision & Real-Time Auditor)](https://github.com/edwardsantacruz35-ui)
> **Zero-API Desktop Automation:** End-to-end robotic process automation that registers hundreds of micro-transactions into desktop ERP systems without native API access.
- **Key Features:** Multi-scale template matching (`cv2.matchTemplate`), dynamic coordinate calibration, pre-submission screen auditing with visual feedback, and asynchronous cloud ledger synchronization.
- **Impact:** Reduced batch transaction registration time by **90%**, with 100% data audit accuracy.

### 3. ⚖️ [Multi-Bank Multi-Currency Reconciliation Engine](https://github.com/edwardsantacruz35-ui)
> **High-Throughput Financial Settlement:** Algorithmic reconciliation suite comparing bank statements (Banesco, Provincial, Mercantil, BNC) against corporate general ledgers.
- **Key Features:** Automated discrepancy detection, daily Central Bank rate (BCV) indexing, fuzzy matching on client descriptions, and mathematical subset-sum bundle matching.

### 4. 📲 [B2B WhatsApp Collections Automation Engine](https://github.com/edwardsantacruz35-ui/bot_whatsapp.py)
> **Automated Debt Reminder Dispatcher:** Headless automation leveraging Python and Selenium to dispatch scheduled, personalized account statements and debt alerts to B2B clients.
